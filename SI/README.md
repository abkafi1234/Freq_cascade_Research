# Supporting Information: experimental data

Generated by `make_si.py` from the canonical result files in `freqcascade/results/*.jsonl`; do not edit by hand. Every value is copied verbatim from those files.

One CSV per experiment. A `source_file` column names the canonical JSONL each row came from, so a group that pools several corpora stays traceable. List- and dict-valued fields (per-epoch loss histories, per-class arrays) are omitted from the CSVs; the raw JSONL released with the code retains them.

## Reproduction

The package that produced these files, the dataset loaders and the cross-validation fold indices are released with the paper (`pip install freqcascade`). Regenerate this directory with:

    cd KBS_shorten && python make_si.py
